TOPOLGIRA DATING APP - SERVICE START COMMANDS
================================================================================

================================================================================
METHOD 1: DOCKER COMPOSE (BACKEND + DB) & LOCAL FRONTEND
================================================================================

[Terminal 1] - Start all backend microservices & databases:
Path: C:\projects\dating\infrastructure\docker
Command:
docker-compose -f C:\projects\dating\infrastructure\docker\docker-compose.yml up --build

[Terminal 2] - Start Frontend React App (Port 5173):
Path: C:\projects\dating\frontend\web-app
Command:
cd C:\projects\dating\frontend\web-app
npm run dev

================================================================================

--------------------------------------------------------------------------------
1. DATABASES (PostgreSQL Port 5432 & Redis Port 6379)
--------------------------------------------------------------------------------
Path: C:\projects\dating\infrastructure\docker
Command:
